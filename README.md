## 怎么选？几个判断维度

**你的用户在哪里？**

这是最核心的问题。如果 80% 的访客都在大陆，那 Pro 系列的 CN2 GIA 是值得的投入；如果面向的是东南亚或者欧洲用户，T1 就够了，还省一大笔钱。

**预算是多少？**

- 月预算 $10 以内：只能选 T1，用优惠码年付，换算下来最便宜
- 月预算 $30-60：EB 系列入门，三网直连，大陆体验不错
- 月预算 $80 以上：才真正有资格谈 Pro 系列，否则钱花在刀刃上的意义就低了

**业务对延迟敏感度**

如果你跑的是静态博客或者流量不大的展示页，EB 系列的延迟对用户来说几乎无感。但如果是实时游戏服务器、视频推流、或者需要频繁大陆-香港往返交互的 API 接口，Pro 系列的那 10ms 差距就是真实可感知的用户体验差异。
